Claude 进程可视化 Mockup

4 种图形化方案对比 · 模拟数据

方案 A
气泡图

面积 = 内存占用，颜色深浅 = CPU 负载，hover 看详情。一眼看出谁最"胖"、谁最"忙"。

面积 = 内存 颜色深浅 = CPU
方案 B
进程树 / 拓扑图

展示主进程 → subagent 父子关系，节点大小 = 内存，连线动画表示活跃通信。

方案 C
实时堆叠面积图

类似 Activity Monitor，每个 Claude 进程一层颜色，实时展示 CPU/内存随时间变化。

Claude 进程 CPU 占用趋势

方案 D
详情卡片 + 双环仪表

每个 Claude 进程一张卡片，CPU/内存各一个环形仪表，底部显示会话 ID、项目目录、运行时长等元数据。
