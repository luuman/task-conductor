Claude Session Messages — 消息体类型完整参考

覆盖 Claude Code 会话 JSONL 中的所有条目类型和 Transcript API 返回的全部 TranscriptBlock 变体。
每个卡片展示渲染效果 + 原始元数据结构，作为逐个优化改进的参考基线。

0a

JSONL 条目类型（原始存储格式）

每个 Claude Code 会话保存为 ~/.claude/projects/{project-path}/{session-id}.jsonl，每行一个 JSON 对象。 共有 7 种 type：

type频率说明
user高用户消息（含文本 + tool_result）
assistant高助手消息（含文本 + tool_use + thinking）
progress极高Hook 执行进度、工具执行进度
system中系统事件（stop_hook_summary、context_pruned 等）
file-history-snapshot中文件变更快照（用于撤销）
queue-operation低消息队列操作
last-prompt极低会话最终 prompt 快照
JSONL 通用字段（每条都有）
{ "type": "user" | "assistant" | "progress" | ..., "uuid": "d094fef5-ed40-44dc-b02b-...", "parentUuid": "d361a269-..." | null, "timestamp": "2026-03-22T14:19:07.685Z", "sessionId": "c72aae2c-e37b-43ca-...", "cwd": "/home/user/project", "version": "2.1.81", "gitBranch": "master", "userType": "external", "entrypoint": "cli", "isSidechain": false, "message": { ... } // user/assistant 类型独有 }
0b

Transcript API 数据结构

后端 GET /api/sessions/{id}/transcript 将 JSONL 解析为 TranscriptMessage[]， 每条消息包含 TranscriptBlock[]。这是前端消费的最终格式。

TranscriptMessage 字段类型说明
rolestring"user" | "assistant"
tsstring | nullISO 8601 时间戳
blocksTranscriptBlock[]内容块数组
modelstring | null仅 assistant，如 "claude-opus-4-6"
TranscriptBlock 字段类型说明
typestring"text" | "tool_use"
textstring | null文本内容（type=text 时）
tool_namestring | null工具名（type=tool_use 时）
tool_inputobject | null工具输入参数
tool_use_idstring | null工具调用唯一 ID
tool_resultstring | null工具返回结果（最多 5000 字符）
tool_errorboolean | null是否错误

从 TranscriptMessage 到最终 React 组件的完整路径。

TranscriptMessage[]
  │
  ├── groupMessagesIntoTurns()
  │     ├── { kind: 'user' }     →  UserCard
  │     └── { kind: 'turn' }     →  AssistantTurnCard
  │           │
  │           ├── turn.texts[]    →  RichTextBlock
  │           │     ├── plain text        → ReactMarkdown + remarkGfm
  │           │     ├── ```code```        → CollapsibleCode + hljs
  │           │     ├── ```mermaid```     → MermaidBlock
  │           │     ├── <task-notification> → TaskNotificationCard
  │           │     └── <system-reminder>  → SystemReminderCard
  │           │
  │           ├── turn.reads[]    →  ReadPillRow
  │           │     ├── Read      → pill + ReadFileView (展开)
  │           │     ├── Grep      → pill + SearchResultPanel (展开)
  │           │     └── Glob      → pill
  │           │
  │           ├── turn.edits[]    →  EditInlineCard
  │           │     ├── Edit      → EditDiffView (LCS diff)
  │           │     ├── MultiEdit → EditDiffView
  │           │     └── Write     → file badge + ✓
  │           │
  │           ├── turn.bashes[]   →  BashStatusLine
  │           │     ├── success   → $ cmd + highlighted output
  │           │     ├── error     → red border + error output
  │           │     └── silent    → $ cmd + PASS badge only
  │           │
  │           └── turn.others[]   →  ToolWidget (通用)
  │                 ├── Agent           → AgentResultView

  │                 ├── WebSearch       → collapsible output
