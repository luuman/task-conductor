BashStatusLine — Bash 专用卡片

当前：Bash 统一包为 ```bash 代码栅栏，丢失命令头部和状态指示。
目标：$ command 提示符 + PASS/FAIL badge + 智能输出高亮 + 静默成功 + JSON 自动检测。

● BEFORE — 通用代码块
$ pytest tests/ -v ============================= test session starts ============================== collected 12 items tests/test_pool.py::test_run_success PASSED [ 8%] tests/test_pool.py::test_run_timeout PASSED [ 16%] ============================== 12 passed in 3.45s ==============================
● AFTER — BashStatusLine
⌨ $ pytest tests/ -v 8 lines PASS
============================= test session starts ============================== collected 12 items tests/test_pool.py::test_run_success PASSED [ 8%] tests/test_pool.py::test_run_timeout PASSED [ 16%] ============================== 12 passed in 3.45s ==============================
● BEFORE — 错误也是通用代码块
$ npx tsc --noEmit src/App.tsx(45,7): error TS2322: Type 'string' is not assignable to type 'number'. Found 1 error in 1 file.
● AFTER — 错误有红色边框和 FAIL badge
⌨ $ npx tsc --noEmit 3 lines FAIL
src/App.tsx(45,7): error TS2322: Type 'string' is not assignable to type 'number'. Found 1 error in 1 file.
● AFTER — 静默成功（无输出时只显示头部）
⌨ $ mkdir -p src/utils && touch src/utils/index.ts PASS
● AFTER — JSON 输出自动检测高亮
⌨ $ cat package.json | head -6 6 lines PASS
{ "name": "task-conductor", "version": "1.0.0", "scripts": { "dev": "vite" } }
实现提示：
在 ResultBlock 的 step.category === 'bash' 分支中：
• 从 step.toolInput.command 提取命令
• step.toolError 决定 PASS/FAIL
• step.toolResult 为空时只渲染头部（静默成功）
• 用 guessBashOutputLang() 检测 JSON/Python/etc，回退到 highlightLog() 终端着色
• 新组件：BashCard，替换当前的 CodeBlock + toFence()

Error 状态渲染 — 所有工具

当前：step.toolError = true 时 ResultBlock 经常返回 null（因为 toolResult 可能为空）。
目标：错误时显示红色错误卡片，包含工具名 + 错误消息。

● BEFORE — 错误消失（返回 null）
（步骤存在但无渲染输出）
● AFTER — Read 错误
READ 📄 nonexistent.ts ERROR
● AFTER — Edit 错误
📄 App.tsx ERROR
Error: old_string not found in file. The file may have been modified.
● AFTER — Bash 错误
⌨ $ python -c "import nope" FAIL
Traceback (most recent call last): File "<string>", line 1, in <module> ModuleNotFoundError: No module named 'nope'
实现提示：
• 在 ResultBlock 顶部增加 error 分支：if (step.toolError) 先于正常渲染
• Read/Grep/Glob error → 红色药丸
• Edit error → 文件名 + ERROR badge + 错误消息块
• Bash error → BashCard 的错误变体
• step.toolResult 存在时显示错误内容，不存在时显示通用 "Tool execution failed"
